# 简介
用于控制激光雷达麦轮小车跑八字赛道，并识别赛道转角处的学院图标。赛道规则见tutorials\小车配置与运动控制\小车配置与运动控制说明.pdf

小车运动控制由esp32负责，视觉模型在树莓派上。

视觉模型采用YOLO。小车电机编号等与tutorials中的材料一致。

# 各文件说明
**tutorials**:赛事官方发布的指导材料、硬件说明、规则

**Capture**:树莓派端用于控制拍照，加载模型，并保存识别结果

**Model training**:
- best.pt:视觉模型参数文件
- extract.py:制作数据集时，从录制的视频中抽帧得到训练用的照片
- match_images.py:从label-studio中导出标注好的数据时，不带照片。且标注文件中的照片名字前加了哈希编码。此程序是为了让数据集中的照片与导出的标注文件中的照片名字对应。
- predict_gui:可以选择要识别的照片并调用模型得到输出结果，用于测试模型。
- train_yolo.py：发起模型的训练，输出参数权重文件。

**calibration**：摄像头标定

**CAR**：
- CAR.ino:小车控制主程序
- 其余文件：主控程序要用到的各种包

# 注意事项
这个标定参数是对相机拍得的原图大小进行去畸变的，这个大小的图片去畸变要消耗一定时间。所以不要尝试利用连续的摄像头画面做什么东西，不然画面肯定会很不流畅！！

**PS**:好像这个摄像头本身就做过去畸变了，不用这个标定参数拍出来的照片就很平直了，用了标定参数反而耗费计算性能......

# 各文件说明
**calibration.py**:生成标定参数的代码

**camera_test.py**:用于检验标定结果。在电脑上运行，按q拍一张照片，并把去畸变的结果放在\output目录下

**camera_calibration_data.npz**:标定参数

**pattern.png**:标定板是由这张图打印得到的

**images文件夹**:存放了用于标定的照片
